# Apple TV Bridge chart

Deploys the standalone `ghcr.io/reydelleon/apple-tv-bridge` service with one replica, Linux host networking for Bonjour discovery, and a retained Longhorn credential volume. A MetalLB LoadBalancer exposes TCP control on `6970` and the authenticated admin interface on `6971`.

## Install through Flux

The `k8s-gitops` release at `default-namespace/apple-tv-bridge/apple-tv-bridge.yaml` references this chart through the existing `personal-charts` HelmRepository. Publish the service image, publish this chart through the chart repository's `master` release workflow, then merge the GitOps release. The configured MetalLB address is `192.168.1.204`; it was unallocated in the cluster at inspection time. This chart's generic defaults let MetalLB allocate an address unless an annotation is supplied.

Set `image.digest` for immutable deployments. The default `latest` tag follows the personal application pattern and uses `Always`; a replacement tag alone does not restart a running pod. The `ghcr-pull-secret` image pull Secret must exist in the workload namespace if GHCR requires authentication. Set `imagePullSecrets: []` for a public image.

```sh
helm lint charts/apple-tv-bridge --strict
helm template apple-tv-bridge charts/apple-tv-bridge --namespace default
```

## Admin access and pairing

Open `http://<MetalLB-address>:6971`. Retrieve the generated password without logging or committing it:

```sh
kubectl -n default exec deploy/apple-tv-bridge -- apple-tv-bridge admin-password
```

The generated password and pyatv credentials reside in `/data` on the Longhorn PVC. An externally managed Kubernetes Secret with a `password` key can be referenced through `adminPasswordSecret`. Use at least 16 characters. No credential values belong in Helm values or Git.

For HTTPS, enable `ingress.enabled`, set `ingress.host`, and set `ingress.tlsSecretName` to an available TLS Secret. `ingress.annotations` accepts the cluster's cert-manager annotations. The default ingress class is `nginx`. Host networking exposes the service listeners on the selected node as well as through the LoadBalancer; apply any required LAN restrictions at those paths. TCP `config.allowed_clients` limits accepted processor source CIDRs.

## Storage and commissioning

`persistence.storageClass` defaults to `longhorn`, with `1Gi` and `ReadWriteOnce`. `persistence.existingClaim` can select a retained claim. Uninstall retains a chart-created PVC using Helm's resource policy. Only one replica and `Recreate` prevent overlapping credential writers/device owners and host-port collisions. ConfigMap changes trigger a pod rollout using its checksum.

Keep the Apple TV awake, scan in the web interface, pair Companion and AirPlay, and verify feedback from actual tvOS apps. Device connection or authentication failures are reported in the application; they do not fail Kubernetes readiness. Readiness and liveness use `/healthz` on the admin listener.

The service repository's `docs/tcp-contract.md` specifies the CP3 connection, CRLF framing, snapshot handling, command IDs, and no-replay recovery. No processor joins or SIMPL program files are generated by this chart.
